# Security Policy

## Supported Scope

Aura provides educational guides, scripts, and architectural patterns. We take security seriously, especially when recommending configurations, terminal scripts, container images, and deployment configurations.

## Reporting a Vulnerability or Security Flaw

If you discover a security flaw in any recommended script, configuration, or code snippet:

1. **Do not disclose the issue publicly** in an open GitHub issue or discussion.
2. Please report the finding by opening a private security advisory via GitHub Security Advisories tab or contacting the core maintainers.
3. Include details regarding:
   - The affected guide / file path
   - The nature of the flaw or vulnerability (e.g., command injection risk, credential leakage)
   - Steps to reproduce or a proposed secure remediation
4. Maintainers will review and merge a patched update promptly.

Thank you for keeping the developer community secure!
